# TechFossil Project Roadmap

## Phase 1: MVP Core (Current)
- [x] Immutable signals archive with multi-faceted filtering
- [x] Technology entity directory with aliases and deduplication
- [x] Historical evolution timelines (2024–2026)
- [x] Interactive Knowledge Graph relationship explorer
- [x] Grounded AI Research Mode using Gemini 3.8 Flash
- [x] 14-stage ingestion pipeline with modular source adapters
- [x] Automated Daily Digests and operational metrics dashboard
- [x] Public datasets in JSON, JSONL, CSV, and Markdown formats

## Phase 2: Scale & Ecosystem Growth (Q1–Q2 2027)
- [ ] Public GraphQL API and Webhook notifications for new releases
- [ ] Vector embeddings integration for hybrid semantic search
- [ ] Model Context Protocol (MCP) Server for direct IDE integration
- [ ] Additional source connectors (Rust crates.io, Go pkg.go.dev, Hacker News API, PyPI RSS)
- [ ] Automated weekly newsletter and Discord / Slack bot integration

## Phase 3: Long-Term Archive (Year 2+)
- [ ] Cross-decade longitudinal dataset analyzing software architectural shifts
- [ ] Automated dependency graph impact simulation
- [ ] Decentralized IPFS / Arweave dataset mirror for permanent preservation
