# Contributing to TechFossil

We welcome contributions from developers, researchers, and open-source maintainers.

## Guidelines
1. **Source Authenticity**: Never fabricate releases, CVE numbers, or benchmarks. All signals must have verifiable upstream URLs.
2. **Deterministic Processing**: Code formatting and normalization must produce repeatable outputs.
3. **Conventional Commits**: Use semantic commit types:
   - `feat(adapter): add new source adapter`
   - `data(signals): update verified archive`
   - `fix(dedupe): improve alias detection`
   - `docs(spec): update architecture documentation`
